# CheerpJ for coding agents

CheerpJ runs Java applications, applets, Java Web Start apps, Oracle Forms and
EBS clients, and Java libraries in the browser, from unmodified JARs. It needs no
local Java, plug-in or server-side JVM.

Everything you need is in the **CheerpJ skill**. Load it before doing anything
else. Use the first way that works:

1. Already installed: use it.
2. With the user's agreement and a shell: `npx skills add leaningtech/skills --skill cheerpj`
3. Claude Code: add the `leaningtech/skills` plugin marketplace and install `cheerpj`.
4. Read it directly: https://cheerpj.com/skills/cheerpj/SKILL.md
5. Or from GitHub: https://github.com/leaningtech/skills

Facts such as versions, the loader tag, API options and browser support are in
the docs: https://cheerpj.com/docs/. Licensing and prices:
https://cheerpj.com/pricing.

Inspect the project before changing anything. Ask the user before installing
software, changing servers or production systems, self-hosting the runtime, or
choosing a licence.
